开始之前：关注计数器会读取哪些数据

为了帮你数关注、在撞限后计时、找出没回关你的人，插件需要读取你在 X 网页上的一些数据。请看完再决定。不同意的话，插件什么都不读。

已同意，插件开始工作了。
好的，插件不会读取任何内容。想用的时候，点浏览器工具栏上的插件图标，再回到这里同意。

读取什么

  • 你每次点「关注」「取关」的结果：成功还是被限制、对方的用户名、发生时间
  • 点关注时你所在的页面地址
    例如某人的粉丝列表、搜索页，用来统计从哪里关注的人回关率高
  • 你浏览 X 时，页面本来就会加载的"你是否关注对方、对方是否关注你"
    只记录你正在关注的人
  • 你自己的 X 用户名和关注总数
  • X 页面上弹出的"关注受限"提示文字

用来做什么

  • 数你每轮关注了几个，快到上限时提醒，撞限后计时
  • 统计回关率，列出没回关你的人
  • 取关太集中时提醒你，避免违反 X 规则
只用于上面这些功能，不用于广告，不出售，不给任何人。

存在哪里

  • 只存在这台电脑的 Chrome 里，不上传到任何服务器，开发者也看不到
  • 关注、取关记录保留 7 天；关注来源和回关状态保留 60 天；未回关名单保留到你清空为止

插件不会做

  • 不会替你关注、取关、发帖、发私信
  • 不读私信、密码、邮箱、手机号
  • 不读 X 以外的网站

随时可以撤回

  • 点工具栏上的插件图标 →「设置」→「撤回同意」：立刻停止读取
  • 同一处的「清空记录」：删除已保存的数据
  • 卸载插件：删除全部数据
